This directory documents assets retained only for the isolated
`/dev/avatar-v5-wardrobe` review laboratory. Nothing here is referenced by
Player Setup, the production Avatar Editor, or Player presentation.

## Universal Base Characters Standard

- Official pack page:
  https://quaternius.com/packs/universalbasecharacters.html
- Official free download page:
  https://quaternius.itch.io/universal-base-characters
- Source archive:
  `Universal Base Characters Standard.zip`

The official pack page advertises 20 hairstyles for the overall pack, while
also stating that only 60–70% is included in the free distribution. The free
Standard archive actually contains these unique hair-related meshes:

- `Hair_Long`
- `Hair_Buns`
- `Hair_Buzzed`
- `Hair_BuzzedFemale`
- `Hair_SimpleParted`
- `Hair_Beard` (facial hair, not a hairstyle)

The laboratory reuses the already approved Long and Buns assets from
`public/avatar-v5-production`. It adds lab-only copies of Buzzed,
BuzzedFemale, SimpleParted, and Beard. No paid Source-version hairstyle is
included or represented as audited.

The lab-only Hair 1 base-colour and normal textures were resized to a maximum
of 1024×1024. Geometry, UVs, skin weights, and material depth remain intact.

## Laboratory processing

The repository script
`scripts/avatar-v5/build-wardrobe-lab-assets.mjs` performs the audit and
conversion:

- inventories source file paths, mesh sections, materials, bounds, animations,
  and skeleton joint names;
- compares each candidate with the protected Universal bone subset;
- removes all but one restrained idle animation from alternate-family previews;
- removes weapon nodes from workplace previews;
- deduplicates and prunes glTF resources;
- emits one GLB per complete legacy character for on-demand lab loading;
- generates a machine-readable compatibility report;
- never writes to `public/avatar-v5-production`.

The pipeline uses:

- `@gltf-transform/core` 4.2.1 — MIT
- `@gltf-transform/functions` 4.2.1 — MIT
- `sharp` 0.34.5 — Apache-2.0

No Character Studio code was copied or adapted. Body masking and compatibility
checks were independently implemented for this repository.

## Eye-colour experiment

The free Universal archive provides only `T_Eye_Brown.png`. The paid Source
version advertises customizable shaders, but those files were not used.

Four lab-only eye variants were generated by recolouring pixels inside a
strict iris mask:

- blue
- green
- hazel
- grey

The algorithm preserves the original pupil, white highlights, eye whites,
surrounding skin pixels, UV layout, and normal map. These variants are
experiments and are not available in production before visual approval.

## Performance

- 21 complete legacy-family GLB previews are retained.
- Each preview contains one idle clip rather than the original 24 animations.
- Only the currently selected candidate is loaded.
- The complete lab asset directory is approximately 28.62 MiB.
- The 21 optimized legacy previews total approximately 24.85 MiB.
- Individual complete-family previews are approximately 0.8–1.6 MiB.
- Production Avatar V5 assets and its default initial payload are unchanged.
